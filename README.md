# 🐾 **Fetch the Facts: Pet Supplies Analysis and Dashboard** 🐾

This project combines **Python** 🐍 and **Tableau Public** 📊 to analyze and visualize pet supplies data. From detailed data cleaning and exploratory analysis in Python to an interactive Tableau dashboard, this project is your one-stop destination for unlocking insights into pet product sales, ratings, and customer behavior! 🐕🐈🐾

---

## **📋 Project Overview**

### Goals:
1. **🐾 Data Cleaning**: Handle missing data, outliers, and prepare the dataset for analysis.
2. **📊 Exploratory Data Analysis (EDA)**: Uncover trends in sales, ratings, and repeat purchases.
3. **🎨 Interactive Dashboard**: Create a playful and engaging Tableau dashboard to present insights.

---

## **🔧 Steps Involved**

### **1. Python Analysis** 🐍
- **Data Cleaning**:
  - Imputed missing values for `Price` and `Rating`.
  - Detected and removed outliers.
- **EDA Highlights**:
  - 🛒 **Sales Distribution**
  - ⭐ **Ratings Distribution**
  - 🔁 **Repeat Purchase Analysis**

---

### **2. Tableau Dashboard** 🐕🐾
Built an interactive dashboard with Tableau Public, featuring:
- **KPIs**:
  - 💵 **Total Sales**
  - ⭐ **Average Product Rating**
  - 🔁 **Repeat Purchase Rate**
- **Visualizations**:
  - 🐾 **Sales by Category**: Bar chart showing category-level performance.
  - 🐶 **Scatter Plot**: Price vs. sales correlation by product type.
  - 🐕‍🦺 **Ratings Distribution**: Horizontal bar chart for product ratings.
  - 🔄 **Repeat Purchases**: Pie chart summarizing customer loyalty.
